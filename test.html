📋 Paste Log Lab - Manual Test Suite

Purpose: Verify core functionality of Paste Log Lab before deployment.

← Back to Paste Log Lab

Setup

Open index.html in a new tab to perform these tests.

Test Cases

Test 1: Load Sample Log

  1. Click the "Load Sample Log" button
  2. Wait for the log to load
Expected:
  • Success message appears: "Successfully loaded sample.log (30 lines)"
  • Results section becomes visible
  • Summary shows 30 total lines
  • Level histogram shows DEBUG, INFO, WARN, ERROR, FATAL counts
  • Error codes section shows ERR-1001, ERR-2003, ERR-3007, ERR-5001
  • Timeline histogram is visible
  • All 30 log lines are displayed

Test 2: Filter by Log Level

  1. Load the sample log (Test 1)
  2. Click on the ERROR chip to deselect it
  3. Observe the filtered results
  4. Click ERROR again to reselect it
Expected:
  • When ERROR is deselected, error log lines disappear
  • Line count updates to show fewer lines
  • ERROR chip becomes outlined (not filled)
  • When ERROR is reselected, error lines reappear

Test 3: Search Filter

  1. Load the sample log (Test 1)
  2. Type "order" in the search box
  3. Observe filtered results
  4. Clear the search box
Expected:
  • Only lines containing "order" (case-insensitive) are shown
  • Line count shows something like "(8 of 30)"
  • Lines include OrderService entries
  • Clearing search shows all lines again

Test 4: Copy Filtered Lines

  1. Load the sample log (Test 1)
  2. Filter to show only ERROR level
  3. Click "Copy Filtered Lines" button
  4. Paste into a text editor
Expected:
  • Success message: "Copied X lines to clipboard"
  • Pasted content contains only ERROR lines
  • Lines are plain text (no HTML formatting)

Test 5: Copy Summary as Markdown

  1. Load the sample log (Test 1)
  2. Click "Copy Summary as Markdown" button
  3. Paste into a text editor or Markdown viewer
Expected:
  • Success message: "Summary copied as Markdown"
  • Pasted content is formatted Markdown
  • Includes headings, bullet lists with log level counts and error codes

Test 6: Drag and Drop File

  1. Save the sample.log file to your computer
  2. Drag and drop it onto the drop zone
Expected:
  • Drop zone highlights when file is dragged over
  • File loads successfully
  • Same results as Test 1

Test 7: File Picker

  1. Click on the drop zone (not the buttons)
  2. File picker dialog opens
  3. Select sample.log
Expected:
  • File picker opens
  • File loads successfully
  • Same results as Test 1

Test 8: Paste Content

  1. Copy some log content from sample.log
  2. Click "Paste from Clipboard" button
  3. Textarea appears
  4. Paste content into textarea
  5. Click "Analyze Pasted Content"
Expected:
  • Textarea becomes visible
  • Pasted content is analyzed
  • Results appear as expected

Test 9: Clear Results

  1. Load the sample log (Test 1)
  2. Click the "Clear" button
Expected:
  • Results section disappears
  • Status message: "Results cleared"
  • Page returns to initial state

Test 10: Empty File Handling

  1. Click "Paste from Clipboard"
  2. Leave textarea empty
  3. Click "Analyze Pasted Content"
Expected:
  • Error message: "Please paste some log content first"
  • No results shown

Test 11: Large File Warning

  1. Create a .log file larger than 5MB (copy sample.log content many times)
  2. Upload the large file
Expected:
  • Warning message appears mentioning file size
  • File still processes (if under 50MB)
  • Results appear correctly

Test 12: Visual Elements

  1. Load the sample log
  2. Inspect visual elements
Expected:
  • Level histogram bars are color-coded (purple, blue, orange, red, dark red)
  • Log lines have syntax highlighting (timestamps, levels, loggers, error codes)
  • Chips have appropriate colors and hover effects
  • Layout is responsive and clean

Test 13: Accessibility

  1. Tab through the interface
  2. Check screen reader labels (inspect aria-label attributes)
Expected:
  • All interactive elements are keyboard accessible
  • File input has aria-label
  • Search input has aria-label
  • Tab order is logical

Test 14: Mobile Responsiveness

  1. Resize browser window to mobile size (or use device emulation)
  2. Load sample log
  3. Test all features
Expected:
  • Layout adapts to smaller screens
  • Buttons stack vertically
  • Text remains readable
  • All features work
